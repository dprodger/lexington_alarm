┌─────────────────────────────────────────────────────────────────────┐
│ 🚀 QUICK START                                                      │
└─────────────────────────────────────────────────────────────────────┘

  1. Make changes in WordPress Admin
  2. Run: ./sync-wordpress-state.sh
  3. Copy CSS, snippets, pages (see below)
  4. Tell Claude: "I've synced current_state, help me with [task]"

┌─────────────────────────────────────────────────────────────────────┐
│ 📂 DIRECTORY STRUCTURE                                              │
└─────────────────────────────────────────────────────────────────────┘

  current_state/
  ├── css/kadence_custom.css          ⚠ MANUAL
  ├── pages/
  │   ├── news.html                   ⚠ MANUAL
  │   ├── home.html                   ⚠ MANUAL
  │   └── [other pages].html          ⚠ MANUAL
  ├── snippets/
  │   └── wpcode-export-[date].json   ⚠ MANUAL
  ├── uploads/                        ✓ AUTO
  └── database_exports/               ⚠ OPTIONAL

┌─────────────────────────────────────────────────────────────────────┐
│ ⚠️  MANUAL SYNC STEPS                                               │
└─────────────────────────────────────────────────────────────────────┘

  CSS:
  └─ WP Admin → Appearance → Customize → Additional CSS
     Copy → Paste into current_state/css/kadence_custom.css

  Snippets:
  └─ WP Admin → WPCode → Tools → Export
     Save to current_state/snippets/wpcode-export-YYYY-MM-DD.json

  Pages:
  └─ Edit page → ⋮ menu → Code editor
     Copy HTML → Paste into current_state/pages/[pagename].html

┌─────────────────────────────────────────────────────────────────────┐
│ 🎯 COMMON SCENARIOS                                                 │
└─────────────────────────────────────────────────────────────────────┘

  Changed News page only:
  └─ ./sync-wordpress-state.sh
     Copy news.html only

  Added new snippet:
  └─ ./sync-wordpress-state.sh
     Export snippets from WPCode

  Tweaked CSS:
  └─ ./sync-wordpress-state.sh
     Copy CSS from Customizer

  Major changes everywhere:
  └─ ./sync-wordpress-state.sh
     Copy CSS + snippets + all changed pages

┌─────────────────────────────────────────────────────────────────────┐
